# Arduino-Kits
Complete Compilation of all my arudino projects. 

I'm an incoming Electrical Engineering freshman at Tennessee Tech (Mechatronics concentration). This repo is my lab notebook: every project gets its own folder, a short write-up, and the code that made it work.

## Projects
1. **Blink** — First sketch. Onboard LED with `digitalWrite(HIGH)` / `digitalWrite(LOW)`.
2. **Button-Controlled LED** — Digital input using `INPUT_PULLUP` and `digitalRead()` to toggle an LED. *(in progress)*

## Hardware on the bench
- Arduino Uno starter kit
- Digital multimeter
- Soldering iron and hot air rework station
